## Glowing Bars 3.5.0

### New

- A new When choice for ready cooldowns in the table, In combat + start: the cooldown also glows at the start of a fight, if it's ready then.

### Changed

- Ready cooldowns no longer glow at the start of every fight: they glow when they come back after you used them. The "Glow ready cooldowns when a fight starts" setting is gone. To keep that glow for a spell, set its When to In combat + start.

### Fixed

- Ready cooldowns no longer glow again each time you change stance, or each time Dominos changes the page, as if they had just come back.
- Bars that Dominos pages with Shift, Ctrl, Alt or the target are now followed, and switching pages that way costs much less.
- A cooldown that was running on another page when a fight started now glows when it comes back.
- Arcane Missiles now glows only for Missile Barrage, not for Clearcasting.
- No more error in dungeons when the game keeps secret who cast a buff on you, such as a totem's.
