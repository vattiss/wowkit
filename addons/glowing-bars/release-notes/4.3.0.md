## Glowing Bars 4.3.0

### New

- Common Questions on the Help tab of the settings (/gb): what to do when the Cooldown Manager changes after every login, an ID from Wowhead doesn't work, the Cooldown Manager's windows don't show, or a buff isn't reminded in a dungeon.

### Fixed

- In a dungeon or raid, a buff the game hides from addons (food buffs, elixirs, an Arcane Censer's) no longer glows while it is up. Your class buffs in the Cooldown Manager's Tracked Buffs are still reminded once they are gone.
