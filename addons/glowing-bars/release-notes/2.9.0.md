## Glowing Bars 2.9.0

### New

- Glowing Bars can now use Blizzard's Cooldown Manager to know which of your buffs are up in a fight, when the game hides them from addons. Reminders in combat are much more exact.
- New Cooldown Manager section in the Options page. Choose how far Glowing Bars may use it: add what it needs, only use what's already there, or not use it at all. If you already had the Cooldown Manager on or use EllesmereUI's, nothing is added until you choose "Add what Glowing Bars needs".
- Glowing Bars keeps the Cooldown Manager running out of sight if you didn't use it before. Tracked Buffs, Essential Cooldowns and Utility Cooldowns can each be shown or hidden.
- Repair Hidden Windows brings back a Cooldown Manager window set to Hidden in Edit Mode.
- Glows now also work on the icons of the Cooldown Manager and on the Stance Bar, and each can be switched on or off under Action Bars That Glow. A spell that's only in the Cooldown Manager gets reminders too.
- The Cooldown Manager's windows and the Stance Bar can stay faint like your other bars.
- The add row of the table now shows what to enter.

### Fixed

- Battle Shout, Blessings and other long buffs cast during a fight no longer glow too early.
- A sleeping bag or campfire added as a Missing buff now finds the buff it really gives.
- The automatic button search now knows the totem buttons.
