## Glowing Bars 1.6.0

### New

- **DaylightUI support**: the glows show on DaylightUI's action bars. Its bar N counts as Action Bar N, so the bar
  switches and the faded bars work on them too.
- **The main bar can be faded** until it glows, like the other bars, on the Settings page.
- **An API for UI addons**: an addon with action bars of its own can register its buttons, and they glow like
  Blizzard's. See [the guide](https://vattiss.github.io/wowkit/glowing-bars-api).

### Fixed

- On a bar its UI addon fades (DaylightUI while the mouse is away), the glowing button now shows in full, with its glow;
  the other buttons stay faded.
