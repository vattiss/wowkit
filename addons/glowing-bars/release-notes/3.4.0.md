## Glowing Bars 3.4.0

### New

- Lightning Bolt glows for shamans when it becomes instant, at 5 stacks of Maelstrom Weapon or with Nature's Swiftness.
- Cultivation glows for Tauren when it's ready, out of combat.
- Soul Link glows for warlocks when it's missing while a demon is out, also for a demon summoned in a fight.

### Fixed

- Glows on Cooldown Manager icons and gamepad buttons now fade with them: a window's Opacity, and a window that fades out of combat.
- In the table's Basic view, the rows now fill the window on characters without reagents.
- A spell you added by hand that is now built in as the same type shows only once.

### Changed

- Spell names in the table no longer end in "(alpha)".
