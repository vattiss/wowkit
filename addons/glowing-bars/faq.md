## Glowing Bars: Common Questions

The Help tab of the settings (/gb) shows these.

### The Cooldown Manager changes after every login.

Glowing Bars adds the spells it needs. To stop it, set Blizzard Cooldown Manager on the Cooldown Manager tab to Only use what's already there or Don't use it.

### An ID from Wowhead doesn't work.

Forever's IDs can differ. Turn on Show spell and item IDs in tooltips on the General tab and hover your own button. Low stock takes the Item ID, everything else a spell ID.

### The Cooldown Manager's windows don't show.

On the Cooldown Manager tab, set the window to Show (e.g. Essential Cooldowns Icons), or press Repair Hidden Windows.

### A buff that falls off in a dungeon or raid isn't reminded.

There the game hides some buffs from addons, like food buffs and elixirs. Your class buffs in the Cooldown Manager's Tracked Buffs are still reminded.
